# Верхняя автоскрываемая панель недавно запущенных приложений и буфера обмена (Top Recent Panel)

**Top Recent Panel** — это верхняя автоскрываемая панель для `driftwm`, выполненная в стиле нижней панели задач (`extras/waybar/touchbar.css`). 

---

## Назначение (Зачем нужна)

- **Быстрый доступ к буферу обмена и скриншотам**: Самый левый блок всегда держит свежий скриншот из Flameshot или скопированный текст для моментального перетаскивания (Drag & Drop) в браузер, мессенджеры или графический редактор.
- **История честных запусков**: Показывает историю приложений и файлов, которые были открыты с нуля (Launch-Only Tracking), а не просто развёрнуты или сфокусированы.
- **Экономия экрана**: В обычном состоянии панель скрыта под верхнюю кромку экрана. При наведении мыши панель плавно выезжает, не перекрывая рабочее пространство.

---

## Основные возможности (Что делает)

1. **Плавное выезжание и заезжание (Smooth Slide Animation)**:
   - Использует `Gtk.Revealer` с анимацией `SLIDE_DOWN` (длительность 250 мс).
   - При подводе курсора к верхнему краю экрана панель плавно выезжает вниз.
   - При уводе курсора панель плавно заезжает обратно наверх.

2. **Выделенный слот буфера обмена (Крайний левый блок)**:
   - Расположен в позиции `0` (самый левый).
   - Автоматически подхватывает новые скриншоты Flameshot (`PNG`) и тексты (`TXT`).
   - Поддерживает прямое перетаскивание мышью (Drag & Drop: `text/uri-list`, `image/png`, `text/plain`).

3. **Одинарная горизонтальная строка**:
   - Строка строго в один ряд без скроллбаров и мерцаний.
   - Справа выводится плашка с названием элемента (`name-badge`) при наведении.

4. **Сохранение при перезагрузке**:
   - История хранит до 25 элементов и сохраняется в `~/.config/driftwm/recent_history.json`.

---

## Запуск и автозапуск

Запуск вручную:
```bash
./extras/scripts/driftwm-recent-panel
```

Для автозапуска в `driftwm` скрипт добавлен в `~/.config/driftwm/config.toml`:
```toml
autostart = [
    "~/Documents/work/scripts/driftwm/extras/scripts/driftwm-recent-panel",
]
```

---

## Хранение и сброс истории

Файл истории:
```
~/.config/driftwm/recent_history.json
```

Сброс истории:
```bash
rm ~/.config/driftwm/recent_history.json
```
